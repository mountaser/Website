2. Server Log Files

When accessing this website, the web server automatically collects and stores technical information in server log files. This data includes:

  • IP address of the requesting device
  • Date and time of access
  • Name and URL of the requested file
  • Data volume transferred and HTTP status response code

The legal basis for this data processing is Art. 6(1)(f) GDPR (legitimate interest). The legitimate interest lies in ensuring technical security, error-free operation, and server integrity. Log data is not combined with other data sources or evaluated for marketing purposes. Server log files are automatically purged after a short retention period.

This website does not set cookies, does not use web analytics or tracking scripts (such as Google Analytics or Matomo), and does not embed advertising networks. No user profiling is conducted.

5. HTTPS Encryption

6. Email Communications

If you contact us via email, the information you provide will be processed solely for handling your inquiry (Art. 6(1)(f) or Art. 6(1)(b) GDPR) and will not be shared without your consent. Your message data will be deleted once it is no longer required.

7. Your Rights under GDPR

Under the EU GDPR, you have the right at any time to:

  • Request information about your personal data stored by us (Art. 15 GDPR)
  • Request correction of inaccurate personal data (Art. 16 GDPR)
  • Request erasure (Art. 17 GDPR) or restriction of processing (Art. 18 GDPR)
  • Request data portability (Art. 20 GDPR)
  • Object to data processing (Art. 21 GDPR)

To exercise any of these rights, simply send an email to the contact address listed above. You also have the right to lodge a complaint with a data protection supervisory authority (in Baden-Württemberg, Germany: Der Landesbeauftragte für den Datenschutz und die Informationsfreiheit Baden-Württemberg).
